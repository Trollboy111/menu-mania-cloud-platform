# Menu Mania Cloud Platform

AI-powered restaurant menu digitization platform built using Google Cloud, OCR, Pub/Sub, and serverless functions.

## Live Demo
https://menu-mania-web-1036303316998.europe-west1.run.app

## Features

- OCR-based menu extraction
- AI-powered menu item translation
- Event-driven cloud architecture
- Google Cloud Pub/Sub integration
- Serverless processing pipeline
- Automated menu cleanup workflows
- Redis caching pst translations 

## Tech Stack

- C#
- ASP.NET Core
- Google Cloud Platform
- Pub/Sub
- OCR APIs
- Docker
- Redis

## Architecture

The platform processes uploaded restaurant menus through an event-driven pipeline using multiple cloud functions for:
- menu upload processing
- OCR extraction
- translation
- cleanup and validation
